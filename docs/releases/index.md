# Releases

This section covers notable Frontile releases: what changed, what it means for
your app, and where to look for the details. Each page favors highlights and,
where it helps, live demos over an exhaustive PR list.

- **[v0.18](./v0.18.md)** — the largest release in the project's history: fourteen
  new components, a rebuilt OKLCH-based design system, and a single consolidated
  `frontile` package.
- **[v0.17](./v0.17.md)** — Table, Avatar, Switch, filterable Select, Portal, and the
  move to Tailwind CSS v4.
- **[v0.16](./v0.16.md)** — the Addon V2 + Glint + template tag migration that moved
  every package onto Ember's modern addon format.

For the complete history, including older versions and patch releases, see the
[GitHub releases page](https://github.com/josemarluedke/frontile/releases).
